## Overview

This project explores how *structured label noise* affects model performance on large-scale vision datasets.  
The `noise_injection.py` script is responsible for generating **noisy label variants** of a cleaned ImageNet dataset using the image embeddings produced by Rushil’s embedding model. These variants are later consumed by the training pipeline to evaluate robustness under different noise patterns.

## What `noise_injection.py` Does

`noise_injection.py` takes in:

- A `.npy` embedding file (generated by Rushil)  
- A clean labels CSV file (produced by Kush & Saeed)  
- Hyperparameters specifying the noise type and severity  

Using these inputs, it corrupts a selected portion of labels by leveraging embedding-space structure. Supported corruption methods include:

- **Nearest-neighbor noise:**  
  Replace a sample’s label with the label of its closest neighbor in embedding space.

- **Cluster-based noise:**  
  Form small clusters using k-nearest neighbors and flip entire clusters to the label of the nearest external cluster.

The output is:

1. A **new labels CSV** with corrupted labels (used by Bhavya’s training pipeline), and  
2. A **log CSV** detailing exactly which labels were changed and why.

## How to Use

Basic usage:

```bash
python noise_injection.py \
    --embeddings imagenet_embeddings.npy \
    --labels imagenet_clean_labels.csv \
    --output-labels labels_noisy.csv \
    --log-file labels_noisy_log.csv \
    --mode nearest_neighbor \
    --noise-level 0.10 \
    --cluster-size 1 \
    --metric cosine \
    --random-seed 42
